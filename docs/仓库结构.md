# 仓库结构

*最后更新：2026-11-22*

```
README.md              给玩家看的安装与使用说明
LICENSE                《SkinForger 使用条款》（源码公开 / source-available）
NOTICE.md              出处、致谢、重写的声明
SOURCE-STATUS.md       产品里每个文件的来源，以及「不含上游代码」的核验数据

src/                   全部源码（能编译出发布的那两个 DLL）
docs/                  说明与开发记录
legacy/                2026-11-17 重写之前的那套 Cecil 工具链，不参与构建
tests/                 测试素材（自定义加载图的各种尺寸）
```

## src/ ——— 产品源码

| 目录 | 是什么 | 产出 |
|---|---|---|
| `core/` | **Core**：`Host/` 按固定顺序跑 `Modules/` 下的十九个模块 | `SkinForger.Core.dll` |
| `main/` | **Main**：2026-11-17 起洁净室重写的自有源码 | `SkinForger.Melon.dll` |
| `main/Pure/` | 不碰 Unity / MelonLoader 的纯逻辑层，可以离线测 | — |
| `main/Tests/` | 那一层的离线测试，617 条 | — |
| `main/Analysis/` | 离线自检工具（Python），查三类「源码里看不见的契约」 | — |
| `<功能>/Runtime/` | 被编译进 Main 的功能源码，十个 | — |
| `Watchdog/` | 游戏退出后做清理的小程序 | `SkinForger_MuseDashWatchdog.exe` |
| `skinforger/` | 附属模组（东方 Project 联动兼容等），不随主包分发 | 各自独立 |

被编进 Main 的那十个 `<功能>/Runtime/`：
`PreviewMvp`（Preview 窗口）、`PreviewSharedCore`（Preview 与游戏共用的判定层）、
`CharacterMeshGeometry`（网格几何）、`AtlasOwnershipFix`（图集所有权）、
`DumpSystemFix`、`SelectionThumbnail`（选择界面封面图）、`ReplacedBackup`（改过的图自动留底）、
`CustomLoadingPic`（自定义加载图）、`FpsLimiterPatch`（帧率上限）、
`AnimationAmplitudePatch`（动画幅度）。

还有一个 `PreviewOriginalContractRestore/`：**已退役**，不参与构建，见那个目录的 README。

### Core 的模块

`src/core/Modules/` 下每个文件夹是一个模块，由 `Host/SkinForgerCoreMod.cs` 按原顺序启动。
挑几个值得看的：

| 模块 | 干什么 |
|---|---|
| `SkinPackages/` | 皮肤库界面、`.sfskin` 包的格式与装载、文字替换、声音替换、字体、锚点（`AutoAnchor`）、扩框画布（`OffsetCanvas`、`PlacementCanvasClamp`） |
| `R4_12MeshCanvas/` | **网格部件扩框**的唯一正确机制（临时缓冲那套） |
| `ElfinMeshCanvas/`、`ElfinFreshPackedRect/` | 小精灵的网格与独立矩形 |
| `CharacterPolygonPackedRectRepair/` | 四边形部件的打包矩形修正 |
| `OriginalStateRestore/` | 「一键换回游戏原样」 |
| `BattleAtlasEdgeIsolation/`、`GameplayAtlasWarmReuse/`、`AtlasBuildAccelerator/` | 图集边缘隔离、热复用、构建加速 |
| `PreviewEnhancements/`、`PreviewLifecycleGuard/` | Preview 的动画控制与生命周期 |
| `HexieBlock/` | 和谐部件拦截 |
| `Bootstrap/` | 让整包住在一个文件夹里（`AssemblyResolve`） |
