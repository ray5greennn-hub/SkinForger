# 开发记录

| 文件 | 内容 |
|---|---|
| `开发历程.md` | 每个功能为什么做成这样，以及一路上哪些做法被证明是错的 |
| `BUG_LOG.md` | 开发过程中实际遇到的 70 个 bug：现象、原因、解法、涉及哪些文件 |

## 为什么公开它

这些坑大多不是 SkinForger 独有的。Spine 纸偶、IL2CPP 下的反射绑定、图集重建后的 UV、
uGUI 的遮罩与字体度量 —— 做同类游戏 Mod 的人会撞上同样的东西。
而一个 bug 真正值钱的部分不是「修好了」，是「为什么一开始会错」，
所以走错的方向和被否掉的做法也写在里面。

## 这不是什么

**不是当前版本的说明书。** 后面的条目会推翻前面的。要看现在怎么回事，请读源码和 `docs/` 下的说明。

**也不是逐日的工作记录。** 那份是私有的，不随仓库发布 ——
里面的技术结论都已经整理进这两份文档，以及 `docs/为什么重写了Main.md`
和 `docs/expansion/扩框机制说明.txt`。
